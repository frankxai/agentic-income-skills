# Request-to-Quote Agent Desk

This is the first reference Outcome Pack for Agentic Income.

It is intentionally narrow:

- B2B service requests only.
- The customer owns the domain, inbox, CRM, data, and production credentials.
- The agent may classify, request missing information, schedule, update the CRM, and draft.
- A human approves prices, quotes, contracts, financial actions, and ambiguous commitments.
- The pack promises a governed process and declared acceptance criteria, never income.

Validate the manifest from the repository root:

    npm run income:validate -- examples/request-to-quote-desk/income-system.json

Create an owned working copy:

    npm run income:init -- --output=../my-quote-desk

Before production use, replace the example principal, domains, provider references, schemas, budgets, terms, system hash, eval results, and evidence.

The JSON Agent Card is an interoperability example. Sign and serve the production card according to the current A2A specification; the legal supplier must remain visible.
