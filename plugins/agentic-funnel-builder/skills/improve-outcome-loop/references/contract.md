# Metric contract

North-star candidate: customers completing the agreed useful outcome per cohort/week. Add contribution after acquisition and attributed human effort. These are proposed measures, not promises.

- Activation = unique eligible users reaching first value / unique eligible starts.
- Acceptance = accepted completed deliveries / completed deliveries submitted. Report unresolved deliveries separately.
- Contribution before acquisition = net-of-tax earned revenue minus refunds/adjustments not already netted, fees, variable model/tool/hosting costs and direct labor.
- After-acquisition contribution subtracts allocated acquisition cost. Fixed overhead and development remain separate.
- Retention needs cohorts, interval and actual use; recurring charges alone are not activation.

For A/B tests use predeclared fixed-horizon or valid sequential methods. Report intervals and practical effect. Small counts require exact methods or an explicit approximation limitation.

Illustrative pilot targets: ten paying design partners, eight completing the core task, seven judging the result useful, median support under thirty minutes/project. These are targets to revisit, not achieved results.
