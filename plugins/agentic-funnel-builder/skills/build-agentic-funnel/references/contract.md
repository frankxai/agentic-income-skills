# Brunson method map

Checked 2026-09-09 against public descriptions and offers. This original adaptation is not a full extraction of every book.

| Source | Principle | Engineering application |
|---|---|---|
| DotCom Secrets | Value ladder and customer journey | Product catalog, useful entry offer, progression, activation |
| Expert Secrets | Mechanism, story, demonstration, objections | Truthful narrative, evidence-linked claims, working demo |
| Traffic Secrets | Dream customer, audience concentrations, owned audience | Partner/source map, useful public artifacts, consented follow-up |
| Unlock the Secrets | Application companion | Original decision records; exact exercises require licensed text |
| Public ClickFunnels offers | Sample/book, optional training, software | Working diagnostic, implementation kit, earned recurring value |

Hook–Story–Offer, Epiphany Bridge, Attractive Character, Soap Opera/Seinfeld sequences and Perfect Webinar are part of the broader teaching. Verify official descriptions or licensed passages before attributing exact details. Do not fabricate the founder's story. Dream 100 also has Chet Holmes provenance; do not attribute every direct-response technique's invention to Brunson.
