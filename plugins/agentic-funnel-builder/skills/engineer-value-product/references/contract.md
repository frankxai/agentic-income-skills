# Product contract

Use an evidence → product → acceptance → offer → journey → delivery → outcomes chain.

| Record | Required substance |
|---|---|
| Buyer | Segment, repeated job, trigger, present workaround, budget owner |
| Evidence | ID, observation, source, date, evidence level, synthetic flag, use rights |
| Product | Version, inputs/outputs, intended use, exclusions, license, maintenance |
| Acceptance | ID, required/optional, grader, baseline, result tied to product version |
| Offer | Contents, price hypothesis, currency/tax basis, timing, refund/support |
| Experiment | Population, denominator, duration, outcome, guardrails, stop decision |

For FrankX's portfolio, verify current contracts: Agentic Income owns accepted paid work; Agentic Passive Income owns maintained assets; GenCreator supplies creator workflows; Starlight supplies shared intelligence.

Agentic Funnel Builder v0.1 is proposed in frankxai/agentic-income-skills under plugins/agentic-funnel-builder. Verify branch/release status before promising availability. Its MCP outputs are advisory; it does not independently verify evidence or execute payments/publication.

Useful prompts:
- Find evidence this buyer already spends time or money on the job.
- Build the smallest artifact that improves the current workaround.
- Show why this could fail even with excellent marketing.
